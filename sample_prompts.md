## Challenging AI output with my own measurements

"Check the POST count. I counted 662 `POST /` requests to 294 distinct IPs; you have 637 to "about 300 websites". One of us filtered differently."

"“290 connection attempts” doesn’t match my count. I get 239 distinct SMTP connections (unique server and source port), which averages about two SYNs per connection and fits the retry explanation. Check which filter gave you 290."

"The “sleep delay” explanation is only one possibility. The host wasn’t completely quiet: I count 201 packets between 13:38:35 and 13:43:50."

"High entropy doesn’t prove encryption. I measured 7.99995 bits per byte: near the maximum, but not exactly 8.0. Compressed data scores just as high."

"Check the reference. Make sure “Dell SecureWorks, 2012” is a real report and actually covers the 2007 start date, Cutwail and ZeuS."
